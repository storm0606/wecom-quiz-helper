# 企微考试

企业微信答题辅助 Android 应用：答题时悬浮窗**实时显示正确答案**，由你**人工点选**作答。

> 只读不点：本应用仅做「读屏 → 查题库 → 显示答案」，**没有任何自动点击/自动作答**行为。

**当前版本：v2.4**（versionCode 15） · Android 7.0+（minSdk 26 / targetSdk 34）

## 功能

### 题库导入与管理
- 支持 **.xlsx / .xls / .docx / .csv**，解析器纯手写（xlsx/zip、xls OLE2+BIFF8、docx 表格、RFC4180 CSV），无第三方解析库；
- 表头自动识别（含 `题目类型` / `题目标题` / `题目答案` 等别名、单列「选项」表头）；无表头时按常见列数猜测布局；
- **手动列映射**：导入时逐列指定「题目/选项/选项A–F/答案/题型/序号」，适配各种非标准题库；
- **特殊题库拆分（v2.4）**：
  - 选项挤在一个单元格（`A xxx B xxx C xxx D xxx`，无 `|`）→ 按字母边界自动拆成独立选项；
  - 答案挤在一个单元格（`A B C` / `A | B` / `A.B.C.`）→ 归一为 `ABC`（字母 A–F，去空白/分隔/标点）；
  - 旧式 `A、正线 |B、停车场 |`（`|` 分隔）继续支持；
- 多题库管理：重命名、删除、设为当前；匹配范围可选**所有题库**或**指定题库**；
- **题库内容查看（v2.4）**：每个题库可「查看」——表头（题型/题目/选项A–F/答案）与内容逐列对应的表格，**每种题型最多展示前 5 题**，用于核对导入映射是否正确。

### 实时读题与匹配
- 无障碍服务监听**企业微信**（`com.tencent.wework`）答题页，提取题干与选项；
- 题干归一化后三级匹配：**精确 → 包含 → 模糊（LCS 相似度）**，跨题库同题不同答案时提示歧义，绝不显示错误答案；
- 错题/回顾场景识别到「正确答案：X」时兜底显示屏幕答案。

### 悬浮窗
- 拖动、收起/展开、双指缩放（0.8x–2.5x）、长答案限高内部滚动；
- 识别到新题时可选反馈：无 / 高亮闪烁 / 背景色轮换（多色色板，可多选）；
- 前台服务常驻，答题页外自动隐藏等待。

### 安全与代码保护
- **2FA 设备绑定**：首次使用输入 6 位动态验证码（TOTP，RFC 6238），绑定设备指纹，换机/清数据需重新验证；
- 2FA 密钥不落明文：分段 XOR 混淆散落 + Android Keystore AES-GCM 二次包装，release dex 中无任何密钥片段；
- 设备指纹与签名绑定；切 debug/release 签名需重新绑定一次。

## 使用流程（首次）

1. 安装 APK 并打开，输入项目所有者提供的 **6 位 2FA 验证码**完成设备绑定；
2. 按提示授予**通知权限**、**悬浮窗权限**（显示在其他应用上层）；
3. 系统设置 → 无障碍 → 开启「企微考试读题服务」；
4. 首页「题库管理」→「导入新题库」选择 Excel/Word/CSV → 核对列映射后确认导入；
5. 回到首页点「开始答题」，悬浮窗出现后进入企业微信答题即可。

## 版本规则

项目铁律：初始 1.0，小版本 **+0.1**（功能/修复/优化），大版本 **+1**（架构/重大功能/不兼容变更）。
每次交付必须在《开发文档》§7 版本记录登记，并同步 Git tag 与 GitHub Release。

## 开发与测试

环境：JDK 17、Android SDK Platform 34、Gradle Wrapper 8.9。

```bash
# Python 原型回归（解析 + 匹配 + 提取全链路）
python3 -m prototype.selftest

# Android JVM 单元测试（63 个）
cd android && ./gradlew :app:testDebugUnitTest

# Release 打包（R8 混淆）
./gradlew :app:assembleRelease
```

> 若本机 `~/.gradle` 不可写（沙箱/权限环境），可指定项目内目录：
> `export GRADLE_USER_HOME="$PWD/../.gcache"` 后再执行 Gradle 命令。

## 已知限制

- 当前仅支持**企业微信**（`com.tencent.wework`）；微信内扫码答题页适配列入 v3.0（暂缓，待真实界面验证）；
- 选项拆分是启发式：仅针对「选项」角色、无 `|` 且满足字母边界规则的单元格；无字母标记又非 `|` 分隔（如 `上行；下行`）不拆；
- v2.4 之前导入的异常题库（选项未拆/答案未归一）不会自动重算，需删除后重新导入；
- 无障碍服务可能被国产 ROM 清理，需在系统设置中保持开启（保活引导页在计划中）。
