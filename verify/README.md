# 真机验证：企业微信答题页能否被无障碍读到

你已经验证了 `adb shell uiautomator dump` 能导出控件树 —— 说明无障碍路线可行。

## ✅ 已确认的真实结构（基于你抓的 window.xml / window2.xml / window3.xml）

企业微信答题页（包名 `com.tencent.wework`）的控件树：

1. **选项是分离的两个节点**：字母节点 `A` 和文字节点 `顺向道岔` 是同一个 TextView 行
   （用 y 坐标中心对齐配对，误差 ≤3px）；
2. **题号行出现两次**：顶部悬浮题号 + 正文题号，需去重；
3. **题号行有两种格式**：
   - 合并式：`第18题(2.00 分)`（单选页）
   - 拆分式：`第26题` + `(2.00 分)` 两个节点（判断/多选页）
4. **多选题的 B/C/D 字母不出现在控件树里**（只有 A 有字母节点）——v1 只显示答案内容不受影响，
   v2 做 ABCD 定位时需要按 y 坐标顺序推断字母；
5. **答完的题才显示"正确答案：X"**：正式作答时不存在 —— 所以必须靠题库匹配；
6. 页面上方有考试标题 / 及格线 / 进度（如 18/50），在题号行之前，可忽略。

`dump_reader.py` 已按上述结构实现，三份真实 dump 全部通过全链路测试
（v1 答案与屏幕"正确答案"交叉校验一致）。

## 抓取控件树（答题时操作）

```bash
# 手机保持在企业微信答题页（停在某一题，屏幕亮着）
adb shell uiautomator dump /sdcard/window.xml
adb pull /sdcard/window.xml
# 拉到本地后放到 wecom-quiz-helper/ 目录下（或任意位置）
```

> 注意：uiautomator dump 不需要切走 app，答题不会被中断。
> 如果企业微信有"防截屏/防录屏"保护，uiautomator dump 一般仍可读取（它走无障碍通道）。

## 用原型工具分析

```bash
cd wecom-quiz-helper
python3 -m prototype.cli sample/sample_bank.csv --dump window.xml
```

脚本会打印：
1. 页面全部文本节点（供人工核对）；
2. 按规则提取出的「题干 + 选项」；
3. 匹配题库后给出的答案。

## 判断标准

| 现象 | 结论 |
|---|---|
| 题干和 A/B/C/D 选项文字都作为独立文本出现 | 无障碍方案完全可行，Android 端直接走读屏 |
| 只能看到一个包含题干+选项的大文本块 | 仍可行，调整提取规则即可（把 window.xml 发我） |
| 完全读不到文字（canvas 渲染等） | 需要 MediaProjection 截屏 + OCR 兜底 |

## 采集建议

- 分别抓 **单选题、多选题、判断题** 三页各一份（同一份 window.xml 里有多题也行）；
- 顺便在答题完成后抓一份（此时屏幕会显示"正确答案"，可以对照验证）；
- 把 window.xml 发给我，我按真实结构调优 `dump_reader.py`。
