# 企微考试 v1.0 · 验收清单

> 逐项执行并核对结果。全部通过后即为 v1.0 验收完成，可正式分发。

## A. 准备（5 分钟）

- [ ] 1. 备份密钥库：将 `android/app/release.keystore` 复制到安全位置（升级必须用同一密钥）
- [ ] 2. 安装 `app-release.apk`（或 debug 版）
- [ ] 3. 打开 App → 「设置」→ 开启「企微考试读题服务」无障碍权限（首页应显示"已开启"）
- [ ] 4. 导入题库：「题库管理」→ 选 `.xlsx/.xls/.docx/.csv` 文件 → 检查列映射是否正确 → 「确认导入」→ 提示"导入成功：N 题"

## B. 题库导入核验（5 分钟）

| 检查项 | 预期结果 |
|---|---|
| 题库1.xlsx（无表头 4 列） | 自动识别：序号/题目/选项/答案，500 题 |
| 题库2.xls（老格式） | 自动识别表头，1129 题 |
| 手动改错一列映射后导入 | 提示缺少「题目」或「答案」列 |
| 多选题答案含 `A\|B\|C\|D\|` | 导入后答题显示选项文字（如 `1.xxx 2.xxx`） |

## C. 真实考试全链路（核心验收，10~20 分钟）

- [ ] 1. 首页点「开始答题」（按钮变「停止答题」，悬浮窗出现，显示"等待题目…"）
- [ ] 2. 打开**企业微信 → 进入一场真实考试**（选择/多选/判断各若干题）
- [ ] 3. 逐题核对：**悬浮窗显示正确答案**，人工点选作答

| 题型 | 预期悬浮窗显示 |
|---|---|
| 单选 | 答案选项的文字（如 `对向道岔`） |
| 多选 | 答案选项文字编号（如 `1.预防为主 2.防消结合`） |
| 判断 | `正确` 或 `错误` |
| 简答 | 题库答案文字 |
| 题库没有的题 | `未命中题库（可尝试补题库或 OCR 兜底）` |

- [ ] 4. 切换题目（上一题/下一题/自动跳题）：悬浮窗跟随更新
- [ ] 5. 拖动悬浮窗到别处：位置改变；点「收起」再「展开」：正常；点「✕」：悬浮窗关闭、按钮回到「开始答题」
- [ ] 6. 期间 App 不应崩溃、卡死

## D. 后台驻留（3 分钟）

- [ ] 1. 答题中途切到别的 App 再回来：悬浮窗仍在，答案仍显示
- [ ] 2. 熄屏 1~2 分钟再亮屏：悬浮窗仍在（若被系统杀死，重新点「开始答题」可恢复——属国产 ROM 正常行为，v1.1 会加保活引导）
