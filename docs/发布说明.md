# 企微考试 · 发布说明

## v2.4（2026-09-02）— 当前正式版

**v2.4 变更（特殊题库适配 + 题库内容读取）**
1. **单格选项拆分**：选项挤在一个单元格的题库（`A xxx B xxx C xxx D xxx`，字母之间是文字/数字，无 `|`）→ 导入时按字母边界自动拆成独立选项 A/B/C…（空格式、点号/顿号紧凑格式、6 选项均支持）；含 `|` 的旧格式不变
2. **单格答案归一**：多选答案集中在一格（`A B C`、`A | B`、`A.B.C.`、`A、B`）→ 归一为 `ABC`（支持字母 A–F，去空格/分隔/标点）；数字填空 `50|100`、判断文字答案不受影响
3. 带表头文件里表头就叫「选项」（单列、无 A–F 后缀）现在也能自动识别为选项列
4. **题库内容读取（「查看」）**：题库管理每个题库新增「查看」→ 表格抽查导入结果——表头行 题型/题目/选项A–F/答案 与内容逐列对应（答案列浅黄高亮），**每种题型最多展示前 5 题**，便于核对列映射是否正确；顶部显示总数与各题型计数
5. 配套：解析器与 Python 原型同步演进、单测新增（见 `模块任务摘要.md`）

> ⚠ 旧版本导入的题库不会自动重算：凡此前导入格式异常（选项未拆开、答案带空格/标点未归一的）题库，请删除后重新导入一次（用「查看」即可发现）。

## v1.0（2026-09-01）

### 发布包
- `android/app/build/outputs/apk/release/app-release.apk`（签名发布包，可直接安装分发）

### 签名信息（务必妥善保存！）
- 密钥库：`android/app/release.keystore`
- 别名：`qweexam`
- 口令：`qweexam2026`
- ⚠️ **重要**：升级版本必须使用同一密钥库签名（否则无法覆盖安装）。
  请将 `release.keystore` 备份到安全位置；此文件一旦丢失将无法对已发布版本做升级。

### 安装与使用流程
1. 安装 App；
2. 「设置」→ 开启「企微考试读题服务」无障碍权限（或在系统无障碍设置中开启）；
3. 「题库管理」→ 选择题库文件（.xlsx/.xls/.docx/.csv）→ 确认列映射 → 导入；
4. 回到首页 → 「开始答题」（自动检查悬浮窗权限，首次需允许「显示在其他应用上层」）；
5. 打开企业微信答题页，悬浮窗实时显示答案，人工点选作答。

### 版本规则
- 小版本 +0.1（功能增改/修复）：v1.0 → v1.1
- 大版本 +1（重大变更）：v1.9 → v2.0
- 每次变更记录在 `docs/开发文档.md` §7 版本记录

### 已知限制（v1.0）
- 多选题答案显示为选项文字编号（题库答案字母仅作参考）；
- .xls 多 sheet 题库暂取第一个 sheet；
- 企业微信改版可能导致读题失效，需按 `verify/` 流程重新抓取控件树适配。
