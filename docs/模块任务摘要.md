## v2.4 特殊题库拆分增强 + 题库内容读取 ✅（2026-09-02，版本：v2.4）

**用户需求**
1. 特殊题库选项/答案都挤在一个单元格：选项 `A xxx B xxx C xxx D xxx`（字母间是文字/数字）、答案 `A B C` / `A | B` → 导入时要分别拆分/归一；
2. 已导入题库支持"读取"抽查：表格形式核对列映射（表头与内容对应），每种题型只取 5 题。

**任务摘要**
- `BankParser.normalizeAnswer`：去空白/分隔/标点后若纯字母（A–F）→ 拼接大写（`A B C`/`A | B`/`A.B.C.`/`A、B` → `ABC`）；数字填空 `50|100`、判断文字仍走可读分支（`50、100`/原样）；
- `BankParser.splitOptions` + 新增 `splitLetterOptions`：无 `|` 的单格连写选项按字母边界拆分（标记 = A–F 后紧跟标点 或 前后成词边界；门槛：≥2 个、串首 A 起始、字母严格递增、每段非空、≤6）→ 空格式/点号顿号紧凑格式/6 选项全支持，误判回退为单选项 A；含 `|` 旧逻辑不变（前缀域扩到 A–F）；
- 表头裸「选项」列自动识别（`COL_ALIASES` 增别名），带表头单列选项库不再丢列；
- `AnswerMatcher.v1Display` 多选字母域扩到 ABCDEF（E/F 选项也能显示文本）；
- **题库内容读取**：`BankListActivity` 卡片新增「查看」→ `BankPreviewActivity`（表格，题型/题目/选项A–F/答案列头与内容逐列对应、答案列浅黄高亮、交替行底色、横向可滑），`BankPreviewModel`（纯函数：每题型抽样 ≤5 题、列按库中实际有内容生成、顶部题型计数）；
- Python 原型同步：`bank_parser.normalize_answer/split_options/_split_letter_options` 等价实现 + `_COL_ALIASES` 增「选项」+ selftest 第 7 步用例。

**测试结果**
- JVM 单元测试 **63/63 全绿**（原 56 + 新增 7：答案归一空格/点号 ×1、单格字母边界拆分 + 不误拆 ×2、端到端 rowsToQuestions 连写题 ×1、预览抽样/计数/列规则 ×3）；
- `python3 -m prototype.selftest` 全绿（含新增"单格连写选项+空格答案"步骤）；
- 回归：题库1.xlsx 500 题、题库2.xls 1129 题解析计数与类型分布不变；
- `assembleRelease`（R8）通过；版本 2.4（versionCode 15）。

**注意（需用户知悉）**
- 拆分是启发式：仅针对「选项」角色、无 `|` 且满足门槛的单元格；无字母标记且非 `|` 分隔的选项（如 `上行；下行`）仍不拆（无法安全推断字母）；
- 旧版本已导入的题库不会自动重算——凡此前格式异常（选项未拆开/答案带空格未归一）的题库请删除重导，「查看」页面即可发现。
