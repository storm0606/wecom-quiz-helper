## 铁律

## 产品
- 名称：**企微考试**（Android / Kotlin）
- 用途：企业微信答题时悬浮窗**实时显示正确答案**；**人工点选，禁止自动点击**
- 监听包名：`com.tencent.wework`

## 题库导入
- 格式：`.xlsx` / `.xls` / `.docx`(表格) / `.csv`（纯标准库解析，.xls 为 OLE2+BIFF8 自研）
- 表头：关键词自动识别（别名库：题目类型→题型、题目标题→题目、题目答案→答案、选项A-F）；**无表头**→按列数猜测（3/4/5/8 列）；失败→**手动列映射**（`--columns 题目:1,选项:2,答案:3`）
- 答案：`A|B|C|D|`→归一化 `ABCD`；判断答案可为字母（含义=该选项文字，需翻译）
- 选项：独立列 或 单列 `|` 分隔（`A、正线 |B、停车场`）；剥离字母前缀
- 题型推断：无题型列时按答案字母数 / 选项特征推 单选/多选/判断/简答
- 存储：SQLite(Room)，归一化题干建索引（表结构见开发文档 §4.5）

## 识别（无障碍读屏，无需截图/OCR）
- AccessibilityService 监听企业微信答题页；后台静默
- 控件树事实（已用真实 dump 定稿）：
  1. 选项=**字母节点+文字节点分离**，同一行，按 **y 坐标中心**配对（误差 ≤3px）
  2. **题号行出现两次**（顶部悬浮+正文）→ 去重（中间无实质内容则跳过）
  3. 题号行两种格式：合并式 `第18题(2.00 分)` / 拆分式 `第26题`+`(2.00 分)`（分值节点跳过）
  4. **多选题 B/C/D 字母节点缺失**（仅 A 有）→ v2 按 y 顺序推断
  5. 答完才显示 `正确答案：X`（正式作答时无）→ 必须靠题库匹配，该行仅作开发期交叉校验

## 匹配
- 归一化：NFKC + 全半角统一 + 去空白/标点 + 小写
- 三级匹配：精确（哈希）→ 包含（屏幕文本为大文本块时）→ 模糊（相似度≥0.78 + 长度粗筛）
- 歧义：命中多题且答案不同 → 全部列出，提示人工判断

## 显示规则 v1（当前）
| 题型 | 显示 |
|---|---|
| 单选 | 答案选项的文字（如 `对向道岔`） |
| 多选 | 答案选项的文字，自动编号 `1.` `2.`…（选项已带数字则不再重复编号） |
| 判断 | 正确 / 错误 |
| 简答 | 题库答案文字 |
| 未命中 | 明确提示，不显示错误答案 |

- **v2（未来）**：按屏幕选项内容定位实际字母（选项打乱也准）；OCR 兜底
